Question 4: Frameset Layout

A frameset replaces the body of an HTML document. The required frameset code is shown below: 

<!DOCTYPE html>
<html>

<frameset rows="30%,70%">

    <frame src="navigation.html">

    <frame src="welcome.html">

</frameset>

</html>

Top frame: Navigation links - Home | About | Contact

Bottom frame: Welcome to My Website

Question 20: Important Head Elements

The following important elements are used inside the head section of this webpage:

  • <title> - Defines the title of the webpage.
  • <meta> - Provides metadata such as charset, description and author.
  • <base> - Sets the base URL for relative URLs.
  • <link> - Connects external resources such as a favicon.
  • <style> - Used for CSS.
  • <script> - Used for JavaScript.

Example of base tag:

<base href="./">
